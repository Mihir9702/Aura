# Investment Committee, Model Router, and Knowledge Library

## Committee — SETTLED authority; Adopted baseline protocol

The approved conceptual roles are Market Evidence Analyst, Event Context Analyst, Business Context Analyst, Challenger, Historical Evidence Analyst, and Adjudicator. Required-role subsets, deadlines and measured escalation thresholds remain OD-08. Market Evidence Analyst interprets code-produced quantitative evidence; it never replaces indicator/feature calculation with LLM math. Event Context Analyst assesses catalysts and event timing. Business Context Analyst assesses company/business evidence. Challenger actively seeks contradictory evidence, hidden assumptions, alternative explanations and thesis invalidation. Historical Evidence Analyst assesses relevant empirical results and their limitations. The Adjudicator runs after the policy-required specialist evidence returns; independent specialists may execute concurrently on a frozen bundle. Do not use majority voting as the primary mechanism. An Adjudicator synthesizes arguments, counterevidence, uncertainty, assumptions, and invalidation conditions into a structured Trade Proposal or an explicit defer/no-trade result.

The coordinator freezes the candidate revision, feature/data snapshot, evidence bundle, cutoff, required roles, deadlines, and budget. Independent roles may run concurrently on that bundle. They return typed findings with citation IDs and uncertainty; they cannot update the candidate, query unrestricted tools, or negotiate an order. A deterministic validator checks schema, references, temporal eligibility, contradictions in instrument/horizon, numeric bounds, and unsupported claims. Invalid output is quarantined and may receive a bounded repair attempt. Repair cannot supply missing evidence.

Adjudication consumes only accepted analyses and labels missing roles, conflicting claims, source dependence, and degraded operation. Confidence is a model assessment, not a calibrated win probability unless evaluated as such. Quantitative expected reward/risk must cite code-produced estimates and assumptions; an LLM number is not an estimator. A proposal needs explicit invalidation and exit logic; uncertainty may yield DEFER or NO_TRADE. Required-role failure blocks that analysis policy; it does not cause automatic role omission. Minimum role requirements and degraded policy are OD-08.

Store concise decision rationale and evidence, not claims to expose private model chain-of-thought. The UI's “reasoning” view shows auditable inputs, structured conclusions, disagreements, and citations. Model disagreement is evidence to inspect, not a count of votes.

## Model Router

All inference uses a server-side workload API. Routing inputs: task type, schema, difficulty/importance class, latency deadline, approved providers/models, data-handling class, token/cost ceiling, prompt version, and replay/evaluation mode. Routing records selected provider/model/version if available, parameters, policy version, input hash, output artifact, usage, latency, retries, and failure.

Adopted baseline behavior: reserve estimated cost before dispatch; enforce per-request, run, daily, and concurrent limits; reconcile actual billed usage afterward. A fallback must satisfy the same schema/privacy/quality capability policy. Cache keys include model, prompt, evidence hashes, cutoff, role, and parameters; stale evidence cannot reuse an old analysis as current. Cache only within retention and provider terms. A model outage yields explicit unavailable analysis; no hidden substitute with weaker validation. Vendor/model selection, budget amounts, and quotas are OD-09/14.

Models receive read-only curated evidence. There is no broker tool, SQL write tool, shell tool, policy mutation tool, or secret access in the Committee. Bounded retrieval requests, if enabled, pass a server-owned allowlist and as-of filtering, with every returned item joining the recorded evidence bundle. Never rely on temperature zero for determinism: persist outputs for replay and separately measure repeated-inference variation.

## Knowledge Library

SETTLED: legally available user-supplied books, papers, textbooks, market/broker documentation, research, experiment results, post-trade analyses, and historical observations support hypotheses. Empirical evidence determines credibility.

Adopted baseline lifecycle: register rights/source → quarantine/import → parse → content hash/version → chunk with stable page/section references → index → retrieve with permission/time filters → cite → supersede or remove according to rights. Metadata includes author, publication time, import time, rights/license, allowed uses, provenance, access scope, content hash, parser version, and empirical-evidence classification. Unknown rights block onward distribution. A reference claim and an Aura-validated experimental result are different record types.

SETTLED: rights-aware versioned metadata/full-text-first retrieval. Embeddings/vector retrieval require evaluation showing material benefit; no vector infrastructure is approved merely by possibility. Corpus, rights/retention and retrieval targets remain OD-10. Retrieval tests assess citation support, relevant recall, staleness, rights filtering, temporal leakage, and malicious-content handling. Documents describing future outcomes must not enter earlier historical decision replays. A modern LLM may already know future outcomes: historical AI backtests must label this contamination and cannot establish prospective alpha alone.

External documents, provider errors, retrieved snippets, and model output remain untrusted. Delimit evidence from instructions, normalize suspicious markup, disable active content, and validate citation existence and authorization. Prompt wording is one layer; privilege separation, restricted egress, typed output, and deterministic gates enforce authority even when the model follows a malicious article. See [operations/security](10-safety-and-operations.md).
